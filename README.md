# Portfolio - Loïc Bodet

Portfolio personnel et professionnel présentant mon parcours, mes compétences, mes projets et mes veilles technologiques.

## 🚀 Pages du site
- **Accueil** (`index.html`) : Présentation générale et navigation.
- **Compétences** (`competences.html`) : Arbre de compétences interactif et tableau de synthèse E5.
- **Projets** (`projets.html`) : Présentation des projets informatiques réalisés.
- **CV** (`cv.html`) : Curriculum Vitae en ligne et téléchargeable.
- **Veille technologique** (`veille.html`) : Articles et axes de veille.

## 🛠️ Technologies utilisées
- HTML5 / CSS3 (Vanilla)
- JavaScript
